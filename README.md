## Hello 👋

My name’s Shep Trundle and I’m a 4th-year student at the University of Virginia studying Computer Science with a professional background in Software Engineering and Data Science. To see some projects I've worked on, please take a look at any of the following repositories.

- [Threshold Hash-Based Signatures and Multi-Party Key Sharing](https://github.com/sheptrundle/Threshold-Hash-Based-Signatures-and-Multi-Party-Key-Sharing-)
   - A cryptography project I worked on at the University of New South Wales which implements a hash-based signature scheme that extends the traditional Lamport one-time signatures into a flexible, distributed and stateful system

- [Course Reviews](https://github.com/sheptrundle/course-reviews)
   - Course registration and review application in Java using FXML and SQLite, allowing users to log in, search for courses, and manage course reviews.

   - A fully complete chess game supporting two players on the same machine. Includes both players perspectives, move/square highlighting, check logic, mate logic, personally-drawn pieces, and other features that a digital chessboard may have.

- [Bus Routes](https://github.com/sheptrundle/bus-routes)
   - A bus routing system in Java and SQLite that processes JSON configuration and bus stop data to recommend bus lines and identify nearby stops.

- [Gin Rummy](https://github.com/sheptrundle/gin-rummy)
